SSH Broker 使用帮助

自动重连

已建立的连接意外中断时，默认尝试重连 3 次，每次间隔 2 秒，可在连接设置中调整。期间保留本机终端及近期输出，但输入不会排队或补发。恢复后是新的远端 SSH 终端，不会恢复远端进程或工作目录；主动断开会停止重试。

在一个工作区管理多个远端 SSH 会话，并让本机终端和自动化工具协作。

建立连接

  1. 点击“新建连接”，填写名称、主机地址、SSH 端口、用户名与密码，也可选择私钥认证。
  2. 点击“连接 SSH”。首次连接时确认服务器身份；已确认的身份会记住。
  3. 等待当前目标状态变为 connected。每个目标拥有独立的本机 Telnet 端口。

历史下拉框保存地址、名称、用户名和端口，不保存密码。选择历史时会回填上次端口，仍可手动修改；新目标会建议避开其它目标和历史记录的端口。

使用本机终端

任何支持 Telnet 的终端均可接入，包括 MobaXterm、PuTTY 等。选择 Telnet 协议，地址填写 127.0.0.1，端口填写对应标签页配置的本机 Telnet 端口。建议使用字符模式，关闭本地行编辑。本机终端不需要再次输入 SSH 账号密码。

同一目标的终端和自动化操作共享同一个 SSH PTY、工作目录及环境。不同目标之间相互独立。

关闭窗口与退出

点击窗口右上角关闭按钮或按 Alt+F4，只会隐藏到系统托盘，已有连接继续运行。点击托盘图标或右键选择“显示窗口”恢复界面。要真正关闭程序，请在托盘菜单选择“退出程序”；存在活动连接时会先确认。托盘图标可能被系统收纳在任务栏的隐藏图标区。

关闭单个目标标签仍会断开该目标，活动目标关闭前会确认。切换标签、隐藏窗口不会断开连接。系统注销或关机时程序正常退出。

自动化接口

默认工作区管道名为 SshBrokerReconnect。sshctl.exe 与主程序位于同一目录。先查询目标列表，再使用返回的目标管道；GUI 当前选中哪个标签不影响命令路由。

sshctl sessions
sshctl session-create --name "Linux board"
sshctl --pipe SESSION_PIPE status
sshctl --pipe SESSION_PIPE send --text "pwd" --cr
sshctl --pipe SESSION_PIPE watch

CLI 配置连接时仍需显式提供已核对的主机指纹。认证凭据使用环境变量或标准输入 JSON，不建议放入普通命令行参数。完整命令、脚本语法和错误码见同目录的 AUTOMATION.md。

写入策略、日志与外观

共享写入允许所有客户端输入；单写入者模式由首个发送者或申请者持有写入权；只读模式禁止输入。退出或断线后不会自动重放命令。

日志按钮打开当前日志根目录。每次 SSH 连接使用独立日志目录，包含事件和原始 RX/TX 数据，可能含有终端中输入或显示的信息。

右上角“外观”可选择明亮、暗色、暖色、淡蓝，包含日志区域。主题、历史和窗口尺寸等偏好保存在 %LOCALAPPDATA%\SshBroker\reconnect-preview\workspace；下次启动会恢复窗口大小和最大化状态，但不会保存密码或自动重连。

重装设备后的服务器身份变化（V2.0.2）

IP 未变但设备重装系统后，SSH 主机指纹可能改变。点击连接时会显示地址、新旧指纹及确认提示。确认是预期设备后选择信任，程序更新记录并保留密码重试一次；取消则保留旧记录。密码登录不会使用私钥文件。自动重连和 CLI 不会自动接受变化的指纹。
