# 多设备工作区设计（V2.0.0）

## 会话与观察对象

默认启动 `WorkspaceWindow` 和 `WorkspaceRuntime`。没有已运行会话时显示欢迎 / 新建页，不自动连接历史目标。每个标签保留自己的 `SessionView`、草稿、发送输入、输出游标、`SnapshotProjection` 和 `BrokerRuntime`。切换标签不关闭其它连接；关闭标签只释放对应的 SSH、Telnet、日志和控制管道。

每个目标仍是单一 SSH PTY，由该目标的 Telnet 和 CLI 共享。工作区根管道默认 `SshBrokerV2`，通过 `sessions` 返回目标 ID、备注名称、独立管道名及权威状态快照。CLI 显式选择目标管道，不依赖 GUI 当前选中的标签。旧单目标 Host 模式保留。

## 历史与端口

`ConnectionHistory` 的持久记录只包含 `host / port / username / name / telnetPort`，以主机（不区分大小写）和 SSH 端口为身份，按最近应用配置排序，最多 200 项。名称允许重名和 Unicode/表情，它是备注，不是标识符。密码、私钥口令及私钥内容不序列化。历史在应用配置时保存，重启后不恢复密码或活动连接。

默认路径：`%LOCALAPPDATA%\SshBroker\workspace\preferences.json`。测试或独立工作区可用 `--data-directory PATH` 指定目录。

下拉选择历史时回填主机、SSH 端口、用户名、备注和上次的 Telnet 端口。已知目标的旧端口只是默认值，即使正被占用也允许选择并手动修改；绑定冲突不会影响其它目标。新主机从 7001 起避开历史端口、当前工作区其它会话的配置端口和系统正在监听的端口。用户在建议更新期间手动编辑端口，会保留用户输入。建议不是端口预留；外部进程仍可能在连接前抢占端口。

输入新主机会清除界面中的旧认证输入与其它目标的主机指纹，避免误用。真实连接仍按原流程匹配可信主机记录或进行首次身份确认。

## 显示与目录

RX/TX/事件监视区提供 明亮、暗色、暖色、淡蓝四种全局配色，切换即时同步到其它标签，配色名称保存在偏好文件。此设置只改变监视区，不改变 Telnet 的 ANSI 数据。

日志根目录旁的按钮按文本框路径创建必要目录并调用系统资源管理器，连接期间也可用。路径错误在页面状态区显示。每个 SSH 会话保留独立的运行日志目录。

## 生命周期与隔离

主窗口关闭时仅隐藏到托盘，连接继续运行。显式退出会清理工作区；若 GUI 附着独立启动的 workspace Host，显式退出会请求停止该工作区。一个目标异常仅使该目标 faulted，不停止其它标签。V2.0.1会按配置有限重连，但不会自动重放指令；重连期间尽量保留本机终端。详见 RECONNECT.md。

旧传输协议、写入策略、主机密钥及日志机制继续复用。本版按需求只做功能回归，没有额外开展安全渗透或大规模压力测试。
